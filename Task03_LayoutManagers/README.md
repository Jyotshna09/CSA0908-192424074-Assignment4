# Task 3 – Campus Library Search Screen

## Objective
To design and implement a responsive Campus Library Search Screen using Java Swing layout managers.

## Technologies Used
- Java
- Java Swing
- AWT Layout Managers
- JTable
- GridBagLayout
- BorderLayout

## Source Code
`src/LibrarySearchScreen.java`

## Features
1. Search books by title.
2. Filter books by category.
3. Display book details in a JTable.
4. Clear search fields and restore all records.
5. Responsive interface using nested layout managers.

## Execution

Open the terminal inside the `src` folder and execute:

```bash
javac LibrarySearchScreen.java
java LibrarySearchScreen
```

## Testing
The application was tested at three window sizes:
- 850 × 500
- 550 × 380
- 1100 × 700

## Output Screenshots
The `output` folder contains screenshots of the application at different window sizes.

The Campus Library Search Screen demonstrates the use of Java Swing components and nested layout managers to create a flexible and user-friendly desktop application.
